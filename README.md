# YT Music Morphe

YT Music built with [RLX Patches](https://github.com/Ramik4/rlx-patches): all [Morphe](https://github.com/MorpheApp/morphe-patches) patches and ready-made settings.

[![Latest release](https://img.shields.io/github/v/release/RAMiK4/yt-music-morphe?label=Download&sort=date&style=for-the-badge)](https://github.com/RAMiK4/yt-music-morphe/releases/latest)

</div>

## 🌟 Features

| | |
|---|---|
| 🧩 **RLX Patches** | All Morphe patches for YT Music with the RLX settings, icons and defaults |
| ⚙️ **Recommended settings** | Ready to use from the first start. Your own changes are always kept |
| 🔔 **In-app update check** | New builds are shown in the app: *RLX settings → Updates* |

The changes of each version are listed in the [releases](https://github.com/RAMiK4/yt-music-morphe/releases).

## 📱 Variants

| Variant | |
|---|---|
| **Amoled** (`…_Amoled.apk`) | Pure black by default (menus #0F0F0F), Material and other themes |
| **Original_BBK** (`…_Original_BBK.apk`, clone `com.apple.android.music`) | RLX dark #0F0F0F by default, Material and other themes, plus Dynamic Island for BBK all devices |

Both variants can be installed side by side. The theme color can be changed at any time: *RLX settings → General*.

## 📥 Install

1. Download the APK of your variant from the [latest release](https://github.com/RAMiK4/yt-music-morphe/releases/latest).
2. Install it. To sign in with a Google account, [MicroG-RE](https://morphe.software/microg) is required.

Updates install over the previous version without losing data.
